# Ebook Plus

**ให้หัวข้อหนึ่งบรรทัด แล้วได้หนังสือทั้งเล่มที่พร้อมส่งโรงพิมพ์ — พร้อมปกและภาพประกอบฟรีจาก Google Flow**

Ebook Plus แยกมาจาก Ebook Auto (to GPT Free) ทำงานเหมือนเดิมทุกโหมด และเพิ่มแหล่งสร้างภาพใหม่คือ
**Google Flow โหมดฟรี (0 เครดิต)** ใช้วาดปกหน้า ปกหลัง ลวดลายพื้นหลัง และภาพประกอบในเล่ม
ได้ไม่จำกัดจำนวน — ดูหัวข้อ [ภาพจาก Google Flow](#ภาพจาก-google-flow)

ส่วนขยาย Chrome ที่ขับหน้าเว็บ ChatGPT ทีละเทิร์นจนได้ต้นฉบับครบเล่ม เรียงพิมพ์ด้วย
[Typst](https://typst.app) ที่รันใน WebAssembly ในเบราว์เซอร์เอง วัดจำนวนหน้าจากเอกสารจริง
ออกแบบปกด้วยกระบวนการของกองบรรณาธิการจริง แล้วส่งออกเป็น PDF · EPUB · DOCX

ไม่มีเซิร์ฟเวอร์ · ไม่ต้องจ่ายค่า API · ข้อมูลทั้งหมดอยู่ในเครื่องคุณ

> **In short (English):** a Chrome extension that turns a one-line topic into a complete,
> print-ready book. It drives the ChatGPT web UI turn by turn, typesets with Typst compiled
> to WebAssembly inside the browser, measures real page counts from the compiled document,
> and exports PDF, EPUB and DOCX. Thai typesetting is a first-class concern.
> No server, no API bill, everything stays on your machine.

## ภาพจาก Google Flow

เลือกการ์ด **ChatGPT + Google Flow** ในหน้าเริ่มต้น (หรือ แหล่งสร้างภาพ → Google Flow)
ต้องล็อกอิน [flow.google.com](https://flow.google.com) ไว้ใน Chrome เดียวกัน

```
ChatGPT วางแผนภาพ (ตำแหน่ง · คำบรรยาย · prompt · ชื่อไฟล์ เช่น cover-front.png, fig-2.1-1.png)
  → เปิด project ใหม่ใน Flow ตั้งชื่อตามหนังสือ
  → ทีละรูป: ตั้งช่องพิมพ์เป็น รูปภาพ · สัดส่วนของช่อง · x1 · โมเดลที่ใช้ 0 เครดิต
             แนบปกหน้าเป็นรูปอ้างอิง → วาด → เปลี่ยนชื่อภาพใน Flow เป็นชื่อไฟล์ที่วางแผนไว้
             → ดึงไฟล์ 2K → เก็บเข้าโฟลเดอร์ของเล่ม → ปรับเป็น 300 dpi → แทรกเข้าหน้าเดิม
```

- **ไม่ครอปส่วนสำคัญทิ้ง** — Flow วาดได้ตรงสัดส่วนเป๊ะ (16:9 · 4:3 · 1:1 · 3:4 · 9:16 ทดสอบกับหน้าจริงแล้ว)
  ช่องภาพประกอบในเล่มถูกวางแผนเป็นสัดส่วนเหล่านี้ตั้งแต่แรก ภาพจึงลงช่องได้ทั้งภาพ
  ปก A5 (151×216 มม. รวมตัดตก) ใช้ 3:4 ตัดขอบรวมราว 7% ซึ่งส่วนใหญ่อยู่ในระยะตัดตกอยู่แล้ว
  และ prompt ของปกสั่งให้ของสำคัญอยู่ห่างขอบ
- **ความละเอียดพอพิมพ์** — ใช้เมนูดาวน์โหลด 2K ของ Flow (3:4 → 1792×2400 px ≈ 300 dpi บน A5)
  ถ้า 2K ไม่มาจะถอยไปใช้ภาพ 1K อัตโนมัติ
- **ไม่เผาเครดิต** — ก่อนกดสร้างทุกรูป ระบบอ่านข้อความ "การสร้างจะใช้ N เครดิต" ของ Flow ถ้าไม่ใช่ 0 จะหยุดทันที
- **ภาพทั้งเล่มโทนเดียวกับปก** — ปกหน้าที่วาดเสร็จถูกแนบเป็นรูปอ้างอิงของทุกรูปถัดไป
  (ใช้ภาพใน project เดิมผ่านเมนู "เพิ่มไปยังพรอมต์" ไม่อัปโหลดซ้ำ)
- **ไฟล์อยู่ในโฟลเดอร์ตามชื่อที่วางแผนไว้** — `_EbookPlus/books/<ชื่อเล่ม>/images/<ชื่อไฟล์>`
  (ไฟล์ดิบ 2K อยู่ใน `generated/`) ต้องกด "เลือกโฟลเดอร์" ใน Studio หนึ่งครั้ง (เช่นโฟลเดอร์ `Ebook Projects` ในโปรเจกต์นี้) — ระบบไม่เขียนลง Downloads
- หน้า Flow ใช้ได้ทั้งภาษาไทยและอังกฤษ · หนึ่งเล่ม = หนึ่ง project ใน Flow ทำต่อจากที่ค้างได้

ปุ่ม "เริ่มสร้าง" ของ Flow ไม่รับคลิกจากสคริปต์ ระบบจึงกดผ่าน `chrome.debugger` (สิทธิ์เดียวกับที่ใช้กดส่งใน ChatGPT อยู่แล้ว)
จะเห็นแถบ "Ebook Plus กำลังแก้ไขข้อบกพร่องเบราว์เซอร์นี้" แวบขึ้นมาตอนกด — เป็นเรื่องปกติ

## ทำไมต้องมีเครื่องมือนี้

การให้ AI "เขียนหนังสือให้หน่อย" ในแชทเดียวได้บทความยาว ๆ ที่ลืมตัวเองตั้งแต่บทที่สาม
และไม่มีทางรู้ว่าพิมพ์ออกมาแล้วหนากี่หน้า โปรเจกต์นี้แก้สามเรื่องที่ทำให้มันเป็น "หนังสือ" จริง

| ปัญหา | วิธีแก้ในระบบนี้ |
|---|---|
| เขียนยาว ๆ แล้วลืมสิ่งที่เขียนไปแล้ว | **Book Bible** — ความจำอยู่ฝั่งเรา ไม่ใช่ฝั่งเธรดแชท สรุปทุกตอน ศัพท์ ตัวละคร คำสัญญาที่ยังไม่จ่ายคืน ส่งกลับเข้าไปทุกเทิร์น |
| ไม่รู้ว่าได้กี่หน้าจนกว่าจะพิมพ์ | **คอมไพล์จริงด้วย Typst** แล้วนับหน้าจากเอกสารที่เรนเดอร์แล้ว ไม่ใช่ประมาณจากจำนวนคำ |
| ปกหน้าตาเหมือนกันทุกเล่ม | **ย่อเนื้อหา → ออกแบบ 3 ทาง → กรรมการให้คะแนน → เลือก** สีและภาษาภาพมาจากอารมณ์ของเนื้อหาจริง |

## ติดตั้ง

1. เปิด `chrome://extensions`
2. เปิด **Developer mode** มุมขวาบน
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `extension` ของโปรเจกต์นี้ (ติดตั้งคู่กับ Ebook Auto ตัวเดิมได้ ไอคอนคนละแบบ)
4. กดไอคอนส่วนขยาย → เปิดหน้า **Studio**

ต้องล็อกอิน [chatgpt.com](https://chatgpt.com) และ [flow.google.com](https://flow.google.com) ไว้ในเบราว์เซอร์เดียวกัน
ครั้งแรกให้กดปุ่ม **ทดสอบ Typst** ก่อน จะโหลด WASM ราว 27 MB แล้วตรวจว่าเรียงพิมพ์ไทยได้ถูกต้อง
ถ้าข้อนี้ไม่ผ่าน อย่างอื่นไม่ต้องดู

## ใช้งาน

กรอกหัวข้อ กลุ่มผู้อ่าน จำนวนหน้า ขนาดเล่ม แล้วกดเริ่ม ระบบจะเดินเองและหยุดให้คุณตรวจงาน
หนึ่งครั้งก่อนสร้างภาพและส่งออก

```
หัวข้อ → สารบัญ → เขียนทีละตอน → ตรวจความต่อเนื่อง → นับหน้าจริง
      → คุณตรวจและแก้ → ปก + ภาพประกอบ → PDF / EPUB / DOCX
```

## สิ่งที่ทำได้

- **นับหน้าได้จริง** — คอมไพล์เอกสารจริงทุกครั้ง เลือกได้ว่าจำนวนหน้าเป็นเป้าหมายคร่าว ๆ (ปล่อยให้
  เนื้อหาดีได้ความยาวตามจริง) หรือต้องเข้าเป้าเป๊ะ (ยอมให้ AI ย่อ/ยืดจนตรง)
- **เรียงพิมพ์ภาษาไทยที่ถูกต้อง** — ตัดคำ แทรก ZWSP และมีด่านตรวจทุกจุดตัดด้วยกฎภาษาไทย
  กันสระลอยขึ้นบรรทัดใหม่ กันไม้ยมกหลุดจากคำ พร้อมชุดทดสอบ
- **ปกที่ออกแบบจากเนื้อหาจริง** — ย่อทั้งเล่มเป็นบรีฟ (อารมณ์ ระดับพลังงาน ฉากรูปธรรม)
  เสนอ 3 แนว ให้กรรมการคนละตัวให้คะแนน 7 ด้าน แล้วเลือก คุณเปลี่ยนแนวเองได้ทุกเมื่อ
- **ภาพประกอบที่วางจากเนื้อหา** — เลือก moment เอง กันภาพซ้ำกันเองในเล่ม และมี "กล่องสรุป"
  ที่ Typst วาดเองเป็นเวกเตอร์ คมทุกความละเอียด ไม่ต้องสร้างภาพ
- **แก้ในเวิร์ดแล้วเอากลับเข้าระบบ** — ส่งออก `.docx` ไปแก้ให้พอใจ แล้วนำกลับมาเรียงพิมพ์เป็น PDF
- **ใช้ได้กับบัญชีฟรี** — งานเขียนกับงานสร้างภาพแยกขาดจากกัน บัญชีที่สร้างภาพไม่ได้
  จะได้ prompt พร้อมขนาดพิกเซลไปสร้างที่ไหนก็ได้ แล้วโยนไฟล์กลับเข้ามา
- **หน้าเปิดบทเต็มหน้า 7 แบบ + สุ่ม** — เส้นคู่ · ชิดซ้าย · มินิมอล · เลขจาง · คลาสสิก (เลขไทย) · กรอบ · นิตยสาร
  เลือกจากป๊อปอัปภาพตัวอย่างที่เรียงพิมพ์จริง พร้อมคำคมเปิดบทที่เขียนจากเนื้อหาบทนั้น (ใส่ชื่อคนดังเฉพาะเมื่อมั่นใจว่าถูกต้อง)
- **นิยายครบชุด** — ปกหน้า-หลังแนวโปสเตอร์หนังที่ตัวหนังสืออยู่ในภาพ · ภาพต้นแบบตัวละคร (แนบรูปตัวเอกได้) และคลังตัวละครใช้ซ้ำข้ามเล่ม ·
  ภาพประกอบทุกหน้าตามเหตุการณ์เด่นของหน้านั้น โดยระบุตัวละครในภาพตามรายชื่อจริงของเรื่อง · แนวนิยายสำหรับผู้สูงอายุ
- **งานอัตโนมัติที่ไม่หยุดเพราะเรื่องเล็ก** — ตรวจจากบทสนทนาว่ายังไม่ได้ส่งจริงก่อนตัดสินว่า ไม่แน่ใจ ·
  จับแถบ แชตหยุดชั่วคราว แล้วเปิดแชตใหม่เอง · สั่ง Google Flow เป็นจังหวะ (เว้น 20–45 วินาที ไม่เกิน 22 ภาพ/ชั่วโมง)
  และหยุดพักทันทีเมื่อ Flow แจ้ง พบกิจกรรมที่ผิดปกติ
- **ทำงานต่อได้เสมอ** — ทุกอย่างอยู่ใน IndexedDB สั่งเขียนตอนที่พลาดใหม่ทีละตอนได้
  สร้างปกใหม่ได้ ย้อนกลับได้ และส่งออก `project.json` ไปทำต่อเครื่องอื่นได้

## ตัวเลขที่วัดมาจริง

| เรื่อง | ค่า |
|---|---|
| คอมไพล์ 40 หน้า | 0.9 วินาที |
| คอมไพล์ 300 หน้า | 5.3 วินาที |
| อักษรไทยต่อหน้า A5 ที่ 15pt | 750 |
| ลูปนับหน้าลู่เข้า | 1–3 รอบ แม้ตั้งค่าเริ่มต้นผิด ±33% |

## สถาปัตยกรรม

```
extension/
  manifest.json        ประกาศสิทธิ์ + CSP + หน้า sandbox
  sw.js                service worker — ส่งต่อข้อความอย่างเดียว ไม่เก็บสถานะ
  ui/studio.*          สมองและโต๊ะทำงาน ต้องเปิดค้างไว้ตลอดงาน
  adapter/chatgpt.js   content script — selector ของ ChatGPT อยู่ในไฟล์นี้ไฟล์เดียว
  adapter/flow.js      content script ของ Google Flow — ตั้งค่า วาด เปลี่ยนชื่อ ดึงไฟล์ 2K
  adapter/flow-main.js ตัวดักไฟล์ 2K ใน MAIN world ของหน้า Flow
  core/flow.js         เลือกสัดส่วนของ Flow + ส่งงาน/รอผลผ่าน service worker
  core/machine.js      เครื่องสถานะของงานทั้งเล่ม
  core/prompts.js      prompt ทุกชนิด รวมกระบวนการออกแบบปก
  core/budget.js       แปลงจำนวนหน้าเป็นงบอักษร และวางแผนยืด/หด
  core/thai.js         นับอักษรแบบ grapheme + กฎการตัดบรรทัดภาษาไทย
  core/db.js           IndexedDB — แหล่งความจริงเดียว
  typeset/             ประกอบเอกสาร Typst และรัน WASM ในห้อง sandbox
  vendor/typst/        typst.ts + Typst compiler (WASM)
  fonts/               Sarabun, IBM Plex Sans Thai
design/                เอกสารออกแบบระบบ
```

**สามเรื่องที่ต้องรู้ก่อนแก้โค้ด** — สมองต้องอยู่ในแท็บไม่ใช่ service worker (MV3 ฆ่า
service worker ใน 30 วินาที) · Typst ต้องรันในหน้า sandbox (CSP) · คำตอบจาก ChatGPT ต้องมาใน
บล็อกโค้ดประกบ sentinel ไม่ใช่อ่าน HTML ที่เรนเดอร์แล้ว

เหตุผลเต็ม ๆ ของทั้งสามข้อ พร้อมรายละเอียดการเรียงพิมพ์ไทยและข้อจำกัดที่แก้ไม่ได้
อยู่ใน [`extension/README.md`](extension/README.md) — **อ่านก่อนส่ง PR**

## ร่วมพัฒนา

ยินดีรับ PR ทุกขนาด สิ่งที่ช่วยได้มากที่สุดตอนนี้

- **selector ของ ChatGPT พัง** — แก้ที่ [`adapter/selectors.json`](extension/adapter/selectors.json)
  ไฟล์เดียว ทับได้จาก `chrome.storage.local` โดยไม่ต้องอัปเดตส่วนขยายด้วยซ้ำ
- **ภาษาอื่นนอกจากไทย/อังกฤษ** — กฎการตัดบรรทัดอยู่ใน `core/thai.js` แยกออกมาแล้ว
- **transport ทางอื่น** — `transport/` ออกแบบให้สลับไปใช้ API หรือโมเดลโลคัลได้โดยไม่ต้องรื้อระบบ
  และ `transport/fake.js` ใช้ทดสอบลูปทั้งหมดได้โดยไม่ต้องยิง ChatGPT เลย

แนวทางของโค้ดในโปรเจกต์นี้: คอมเมนต์อธิบาย **เหตุผล** ไม่ใช่อธิบายว่าโค้ดทำอะไร
ทุกกฎที่แปลกตามักมาจากอาการที่เจอในเล่มจริง เขียนไว้ว่าเจออะไรมาถึงต้องมีบรรทัดนั้น

## ข้อควรรู้ก่อนใช้

- **การใช้สคริปต์ขับหน้าเว็บ ChatGPT ขัดกับเงื่อนไขการใช้บริการของ OpenAI** ที่ให้เข้าถึงแบบ
  อัตโนมัติผ่าน API เท่านั้น มีความเสี่ยงต่อบัญชีของคุณ ใช้โดยรับความเสี่ยงเอง
- **การใช้สคริปต์ขับหน้าเว็บ Google Flow ก็มีความเสี่ยงแบบเดียวกัน** — Google อาจจำกัดการสร้างภาพ ("พบกิจกรรมที่ผิดปกติ")
  หรือบัญชีได้ ระบบเว้นจังหวะและหยุดเมื่อโดนเตือน แต่ไม่ได้รับประกันว่าจะไม่โดน ถ้าต้องสร้างภาพจำนวนมากเป็นประจำ ให้ใช้ API ที่เปิดให้ใช้อย่างเป็นทางการ
- ลิมิตข้อความของแพ็กเกจ ChatGPT คือเพดานจริงของระบบ ชนแล้วระบบหยุดและรอให้คนสั่งทำต่อ
- ต้องเปิดเครื่องและเปิดแท็บค้างไว้ ไม่ใช่บริการบนคลาวด์
- คัดลอกข้อความไทยจาก PDF ที่ Typst สร้างยังไม่ได้ (ตาราง ToUnicode ของ Typst ยังไม่รองรับไทย)
  ให้แจก EPUB ควบคู่ไปด้วยถ้าผู้อ่านต้องค้นหาข้อความได้ — ระบบเตือนเรื่องนี้ให้ทุกครั้ง
- งานทั้งหมดอยู่ใน IndexedDB ล้างข้อมูลเบราว์เซอร์แล้วงานหาย ให้ส่งออก `project.json` เก็บไว้
